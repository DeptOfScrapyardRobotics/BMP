# Role

I2C/SPI temperature + barometric-pressure driver for Bosch BMP280. Extends `GeneralPurposeIO\Circuits\Types\SensorIC` and implements `BootSequence` + `Waveforms\Contracts\Environment\MeasuresTemperature` + `MeasuresBarometricPressure`.[^bmp280]

App-facing wrapping is waveforms `PressureTemperatureSensor` / `Barometer` / thermometer helpers (capability inject), not a second chip contract here.

# Attributes

```php
#[IntegratedCircuit('I2C', 'SPI')]
#[Pinout(
    ['I2C' => ['driver', 'device', 'slave']],
    ['SPI' => ['driver', 'device', 'chip_select']],
)]
```

Index-aligned protocol options: I2C alone, or SPI with chip-select.[^bmp280]

# Factories

| Factory | Notes |
|---------|-------|
| `::{i2c}(…)` | `I2C::adapter` → bus → `slave` (default `BMPI2CAddress::SDO_GROUNDED` = `0x76`) → `fromI2CBus` |
| `::fromI2CBus(I2CSlave $i2c, …)` | Already-open slave |
| `::{spi}(…)` | `SPI::adapter` → device → mode 0 / 100 kHz → `select($chip_select)` → `fromSPIBus` |
| `::fromSPIBus(SPIDevice $spi, …)` | Already-open SPI device |

Ctor injectables: IIR filter, overscan temp/pressure, standby, op mode. Default `boot_now` is **true** on factories; constructor default is **false**.[^bmp280][^address]

# Measurement surface

Shared via `BMP280InternalAPI` (used by `BMP280API`):[^internal-api]

| Method / property | Meaning |
|-------------------|---------|
| `temperature(TemperatureUnit $unit = CELSIUS): float` | Compensated temperature; waveforms unit convert |
| `pressure(PressureUnit $unit = HECTOPASCAL): float` | Compensated pressure; throws if overscan_pressure disabled |
| `measureTemp` / `measurePressure` | **Deprecated** aliases → `temperature` / `pressure` |
| `$temperature` / `$pressure` | `__get` → Celsius / hPa via the public verbs |
| `getAltitude()` / `$altitude` | Derived from pressure vs sea-level pressure |
| `close(): void` | Closes carrier transport |

Raw helpers (`getTemp`, `readPressure`) stay on the API trait for compensation; public Measures* verbs are the distance-pattern surface.[^api]

# Boot

- Uses `GeneralPurposeIO\Contracts\Circuits\BootScaffolding`.[^internal-api]
- `_boot()`: chip-id check (`0x58`) → soft-reset → read coefficients → write ctrl_meas + config.
- Wire path: `BMPCarrierTransport` over `I2CSlave` **or** `SPIDevice` (Nab `Splices16Bits` for low-byte helpers).[^transport]

# Units

Units are `Waveforms\Contracts\Sensors\Enums\TemperatureUnit` and `PressureUnit` — **not** Fabricate sensor enums. See [Fabricate leftovers](../traps/fabricate-leftovers.md).
